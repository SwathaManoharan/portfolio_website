# Swatha Manoharan — Portfolio Website

A **super animated portfolio** built with React, Framer Motion, and React Icons.

## ✨ Features
- Animated hero with typewriter effect
- Scroll-triggered animations on every section
- Interactive skills grid, project cards, experience timeline
- Contact form with social links
- Fully responsive dark-themed design

## 🚀 Run Locally

```bash
cd app
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view it.

## 🏗️ Build

```bash
cd app
npm run build
```

The production build lands in `app/build/`.
